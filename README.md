# BulkSend Web 🚀

> **Live App:** https://kapoorva1710.github.io/bulksend-web

A **100% browser-based** Bulk SMS Broadcasting web app. No downloads, no commands, no server — just open the link and use it.

## ✨ Features
- 👤 Add contacts manually or import via CSV
- 📁 Drag & drop CSV upload
- ✉️ Compose and send bulk SMS campaigns
- 📊 Campaign history with delivery stats
- 💾 All data saved in browser (localStorage)
- 🌙 Premium dark glassmorphic UI

## 🚀 How to Use
1. Open → **https://kapoorva1710.github.io/bulksend-web**
2. Click **⚙️ SMS Gateway** and enter your Android SMS gateway URL
3. Add contacts or upload a CSV
4. Type a message and hit **Send to All Contacts**

## 📱 SMS Gateway
Uses the **RestSMS** Android app as the SMS gateway. The gateway must be on the same network as the device opening the web app.
